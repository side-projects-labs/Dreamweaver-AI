# 프로젝트 문서 이미지

- public/project/dreamweaver-form.png는 2026-11-13 https://dreamweaver-ai-beta.vercel.app/ 에서 실제 입력 화면을 Playwright Chromium으로 캡처한 원본입니다.
- viewport는 1600×1100, device scale factor는 1이며 모의 응답·생성 결과를 삽입하거나 화면을 수정하지 않았습니다.
- dreamweaver-generating.png는 같은 배포 서비스에서 동화책 생성을 시작한 실제 화면입니다. 생성 전 기본 미리보기를 완성된 삽화로 설명하지 않습니다.
- dreamweaver-cover.png와 dreamweaver-reading.png는 본문·삽화 생성 완료 후 실제 책 영역을 Playwright로 캡처한 표지와 본문입니다. 화면 합성이나 응답 대체를 하지 않았습니다.
- 본문·삽화 생성과 이전·다음 페이지 이동을 확인했습니다. 공유 버튼을 통한 공개 저장은 실행하지 않았으므로 공유 저장·조회 검증으로 설명하지 않습니다.
- PROJECT.md의 이미지는 공개 저장소에 먼저 푸시한 이미지 커밋 5ee132db7756884cf49d0358028979ac76a93594의 raw GitHub URL을 사용합니다. 기본 브랜치 반영 전에도 같은 파일을 조회할 수 있으며 이후 문서 변경과 분리해 캡처 원본을 고정합니다.
- PROJECT.md는 image 메타데이터를 생략해 포트폴리오에 이미 등록된 대표 이미지를 유지합니다.
